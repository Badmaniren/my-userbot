# Текущий эпик Унги

## Анализ новостного сентимента и рыночных настроений

- market_news_sentiment_analyzer: Создаем базу для нового эпика по анализу тональности рыночных новостей и текстов с полным соблюдением стандартов античита.
- market_sentiment_digest: Связываем анализатор новостного сентимента с генератором портфельного дайджеста для обогащения отчетов настроениями рынка
