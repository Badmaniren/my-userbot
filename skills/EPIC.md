# Текущий эпик Унги

## Комплексный мониторинг здоровья системы: Сбор телеметрии → Анализ отчетов → Экспорт сводок

- system_health_reporter: Создаем базовый модуль генерации отчетов здоровья системы как первый шаг нового эпика мониторинга
- system_health_aggregator: Комбинируем генератор отчетов и дашбордов для агрегации метрик в рамках текущего эпика
- system_health_telemetry_collector: Объединяем агрегатор и репортер здоровья для реализации этапа анализа отчетов в рамках текущего эпика.
- system_health_audit_pipeline: Объединяем сбор телеметрии и агрегацию для продвижения этапа анализа отчетов в рамках текущего эпика мониторинга.
