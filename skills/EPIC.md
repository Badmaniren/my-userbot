# Текущий эпик Унги

## Система проактивной диагностики: агент проверки здоровья → сборщик инцидентов → автоматическое исправление

- ai_diagnostic_agent: Создаем базового агента диагностики для мониторинга доступности и раннего обнаружения сбоев.
- diagnostic_reporter: Интегрируем диагностического агента и пайплайн ошибок для автоматического создания сводных отчетов о здоровье системы в рамках текущего эпика.
