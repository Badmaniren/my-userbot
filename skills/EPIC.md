# Текущий эпик Унги

## Мониторинг исполнения сделок и адаптивное управление рисками

- market_portfolio_monitor: Запуск нового эпика для обеспечения непрерывного контроля исполнения торговых ордеров в условиях стресс-сценариев.
- market_portfolio_monitor: Рефакторинг market_portfolio_monitor укрепляет базовый уровень контроля исполнения ордеров в рамках текущего эпика по адаптивному управлению рисками.
