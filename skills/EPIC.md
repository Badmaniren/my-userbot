# Текущий эпик Унги

## Самовосстанавливающаяся экосистема: Анализ ошибок → Генерация патчей → Верификация → Автофикс

- error_recovery_hub: Создаем фундамент для эпика — модуль сбора и анализа ошибок для преодоления провалов предыдущих циклов.
- patch_validator: Создаем модуль patch_validator для безопасной верификации патчей перед автофиксом, развивая текущий эпик самовосстановления.
