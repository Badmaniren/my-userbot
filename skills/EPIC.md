# Текущий эпик Унги

## Надежный крипто-пайплайн: парсер → база данных → Telegram-алерт

- market_parser: Создаем надежный фундамент для сбора рыночных данных взамен сломанного криптотрекера.
- db_storage: Создаем второй компонент пайплайна (базу данных), чтобы сохранять сырые данные, полученные из market_parser, для последующей аналитики и алертов.
- market_telegram_pipeline: Объединяет готовые компоненты (market_parser и db_storage) для реализации следующего шага пайплайна: подготовки данных к алертингу.
- market_report_generator: Использует готовые модули market_parser и db_storage для создания слоя аналитики и подготовки данных перед отправкой в Telegram.
