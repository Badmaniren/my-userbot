# Текущий эпик Унги

## Надежный расчет VaR с поправкой на ликвидность

- market_portfolio_var_liquidity_core: Создание фундаментального модуля для вычисления скорректированного по ликвидности VaR без использования запрещенных античитом конструкций.
- market_portfolio_var_liquidity_core: Создание модуля валидации расчетных метрик VaR на базе готового liquidity_core, что развивает цепочку надежного вычисления риска.
