# Текущий эпик Унги

## Автономная система предиктивной защиты и авто-хеджирования портфеля

- market_portfolio_stress_reporter: Запуск нового эпика для создания автономного стража, который связывает предиктивный расчет VaR и механизмы хеджирования в единый контур защиты.
- market_portfolio_predictive_var_hedge_synthesizer: Комбинирует предиктивный VaR и авто-хеджирование в единый композитный модуль для реализации бесшовного контура защиты портфеля.
- market_portfolio_predictive_var_hedge_synthesizer: Рефакторинг ключевого модуля синтеза хеджа закрепляет автономный контур предиктивной защиты, устраняя слабые места перед завершением эпика.
