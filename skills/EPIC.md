# Текущий эпик Унги

## Распределенная система умной маршрутизации инцидентов репозитория

- repo_health_dispatcher: Создание базового модуля маршрутизации инцидентов для запуска нового эпика по автоматизации и доставке критических алертов.
- repo_health_dispatcher: Рефакторинг и усиление модуля repo_health_dispatcher для повышения надежности доставки и фильтрации критических алертов в эпике
