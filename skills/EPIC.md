# Текущий эпик Унги

## Анализ и пост-мортим инцидентов

- incident_post_mortem_service: Запуск нового эпика для автоматизированного анализа завершенных инцидентов и выработки рекомендаций
- incident_post_mortem_service: Добавляет модуль архивации для сохранения отчетов, созданных incident_post_mortem_service, продвигая текущий эпик анализа инцидентов.
- incident_post_mortem_service: Добавляет модуль архивации для сохранения отчетов, созданных incident_post_mortem_service, продвигая текущий эпик анализа инцидентов.
- incident_post_mortem_service: Добавляет надежный слой хранения и поиска для отчетов, создаваемых incident_post_mortem_service, что позволяет накапливать базу знаний по инцидентам.
- incident_knowledge_base_searcher: Создает поисковый движок по базе знаний пост-мортим отчетов для сопоставления текущих инцидентов с историческими решениями.
- incident_post_mortem_service: Добавляет модуль оптимизации рекомендаций для повышения эффективности мер по предотвращению повторных инцидентов.
- incident_post_mortem_service: Модифицирует существующий сервис анализа инцидентов для работы с массовыми историческими данными, завершая ключевой этап эпика.
- incident_post_mortem_service: Создает визуализатор для отчетов incident_post_mortem_service, расширяя возможности анализа и представления исторических данных инцидентов.
