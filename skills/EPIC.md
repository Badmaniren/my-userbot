# Текущий эпик Унги

## Аналитическая система трендов и прогнозов здоровья репозитория

- repo_health_metric_validator: Создаем базовый сборщик метрик как основу для будущего анализа трендов здоровья кода
- repo_health_incident_tracker: Модуль обеспечивает хранение временных рядов метрик валидатора, создавая базу данных снимков для вычисления трендов здоровья.
- repo_health_metric_validator: Улучшаем базовый сборщик метрик, чтобы обеспечить чистоту данных для последующих модулей трендов.
- repo_health_metric_validator: Исправление и стабилизация модуля repo_health_metric_validator для обеспечения точного потока метрик в систему трендов.
