# Текущий эпик Унги

## Система продвинутой симуляции и бэктестинга торговых стратегий

- market_portfolio_scenario_simulator: Создаем базовый симулятор исполнения ордеров для запуска нового эпика по продвинутой симуляции торговых стратегий.
- market_portfolio_scenario_simulator: Проводим рефакторинг базового симулятора, повышая его надежность и отказоустойчивость для продвинутой симуляции торговых стратегий.
- market_portfolio_scenario_simulator: Улучшаем надежность симулятора сценариев для продвинутой симуляции торговых стратегий после сбоев в бэктестере.
- market_portfolio_scenario_simulator: Улучшаем и укрепляем текущий симулятор сценариев для фиксации стабильной базы симуляции.
- market_portfolio_slippage_model: Добавляем расчет проскальзывания и рыночного воздействия (market impact) для реалистичной симуляции исполнения сделок в торговых сценариях.
- market_portfolio_scenario_simulator: Интегрируем расчет рыночного воздействия и проскальзывания в текущий симулятор сценариев для перехода к продвинутому бэктестингу.
- market_portfolio_execution_pipeline: Объединяем расчет динамического проскальзывания и базовый симулятор портфельных сценариев в реалистичный пайплайн исполнения ордеров.
