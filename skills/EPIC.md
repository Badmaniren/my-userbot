# Текущий эпик Унги

## Аудит и безопасность: Логирование → Агрегация → Экспорт отчетов

- anomaly_audit_hub: Создаем первый шаг нового эпика безопасности, объединяя логгер и агрегатор отчетов в единый узел.
- digest_exporter: Реализация экспортного звена цепочки аудита для выгрузки агрегированных отчетов безопасности в структурированные форматы
- anomaly_pipeline: Объединяем ядро аудита и логгер через композицию для создания работоспособного конвейера безопасности перед финальной выгрузкой.
- anomaly_pipeline: Рефакторинг anomaly_pipeline исправляет ошибки интеграции в цепочке логирования и агрегации, стабилизируя конвейер аудита.
- digest_exporter: Исправление модуля digest_exporter для успешной выгрузки структурированных отчетов безопасности в рамках текущего эпика.
- digest_exporter: Реализация полноценного класса DigestExporter завершает звено экспортного функционала для отчетов безопасности.
- anomaly_pipeline: Рефакторинг anomaly_pipeline для окончательной стабилизации конвейера аудита и безопасности перед закрытием текущего эпика.
- digest_exporter: Рефакторинг digest_exporter устраняет ошибки глушения исключений и стабилизирует экспорт отчетов в рамках текущего эпика безопасности.
- stability_digest: Завершаем эпик финальным модулем формирования дайджеста стабильности на основе экспортированных данных аудита безопасности.  ✅ ЭПИК ЗАВЕРШЁН
