# Текущий эпик Унги

## Конвейер безопасного автоисправления: Анализатор → Оценщик → Верификатор

- patch_evaluator: Создание модуля patch_evaluator запускает новый эпик автоматизированного контроля качества патчей, выступая связующим звеном между анализом изменений и их последующей верификацией.
- patch_analyzer: Реализация первого звена конвейера (Анализатор), извлекающего детальную структуру и статистику патча для последующей оценки рисков.
- patch_checker: Связывает Анализатор и Оценщик в единый контур предварительной проверки патчей, подготавливая структурированный вердикт безопасности перед фазой верификации.
