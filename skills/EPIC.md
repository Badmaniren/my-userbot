# Текущий эпик Унги

## Автоматизация хеджирования по результатам стресс-тестов

- market_portfolio_stress_recovery_coordinator_bridge: Создание фундамента для передачи данных из симулятора в исполнитель, устраняя разрыв в цепочке автоматического хеджирования.
- market_portfolio_stress_auto_hedge_sync: Композиция компонентов для диспетчеризации хедж-сигналов на базе стресс-тестов и рекомендаций советника.
- market_portfolio_stress_auto_hedge_sync: Объединяет конвейер стресс-тестов с механизмом синхронизации автохеджирования для полноценного сквозного исполнения сигналов.
- market_portfolio_stress_auto_hedge_sync: Исправление и рефакторинг market_portfolio_stress_auto_hedge_sync для завершения цепочки автоматического хеджирования по стресс-тестам.
