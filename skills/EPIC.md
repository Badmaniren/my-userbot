# Текущий эпик Унги

## Система предиктивного анализа сбоев: Анализ трендов → Прогнозирование → Автоматическая профилактика

- incident_trend_analyzer: Запуск нового эпика: создаем базовый модуль анализа трендов на основе накопленной истории инцидентов.
- incident_trend_forecaster: Комбинируем анализатор трендов и метрики патчей для создания модуля прогнозирования возможных сбоев в системе.
