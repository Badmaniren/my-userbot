# Текущий эпик Унги

## Система оперативного оповещения и реагирования на стресс-аудит портфеля

- market_portfolio_alert_dispatcher: Создание базового диспетчера алертов для запуска нового эпика мониторинга и автоматического оповещения рисков
- market_portfolio_stress_recovery_coordinator_bridge: Комбинируем диспетчер и хранилище для оперативного оповещения по результатам стресс-аудита
