# Текущий эпик Унги

## Аудит зависимостей: сканирование манифестов → онлайн-проверка уязвимостей → авто-обновление

- dependency_scanner: Шаг 1: создание базового модуля сканирования зависимостей репозитория для последующей проверки безопасности.
- vulnerability_analyzer: Шаг 2: создание модуля анализа уязвимостей на основе уже созданного сканера зависимостей.
- vulnerability_updater: Шаг 3 (финальный): композиция сканера и анализатора уязвимостей для реализации автоматического обновления найденных уязвимых зависимостей.  ✅ ЭПИК ЗАВЕРШЁН
