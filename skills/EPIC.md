# Текущий эпик Унги

## Автоматическая система генерации релизных заметках: Сбор Git-истории → Обогащение данными аудита → Публикация дайджестов

- changelog_generator: Шаг 1: Создание фундаментального компонента для извлечения и категоризации Git-коммитов при формировании списков изменений.
- release_notes_composer: Шаг 2: Комбинирование базового генератора changelog с аудитом репозитория для глубокого обогащения данных релизных заметок.
