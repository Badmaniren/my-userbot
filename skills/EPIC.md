# Текущий эпик Унги

## Контур глубокого анализа аномалий: Фильтрация → Детекция → Корреляция → Визуализация

- anomaly_filter: Запускает новый эпик контура анализа аномалий созданием первого звена — модуля фильтрации сырых данных.
- anomaly_pipeline: Объединяет фильтр и детектор аномалий (второй шаг контура анализа аномалий после anomaly_filter).
- anomaly_visualizer: Интегрирует корреляцию аномалий с визуализатором для завершения контура анализа данных.
- anomaly_correlator: Доработка модуля anomaly_correlator для закрытия ключевого звена корреляции аномалий перед финальной визуализацией.
