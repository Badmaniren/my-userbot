# Текущий эпик Унги

## Система комплексного аудита и синтеза метрик репозитория

- repo_audit_synthesizer: Запуск нового эпика по созданию центрального синтезатора аудита для объединения разрозненных метрик репозитория.
- repo_audit_aggregator_pipeline: Создание конвейера агрегации связывает центральный синтезатор с мониторингом для продвижения комплексного аудита.
