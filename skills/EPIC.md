# Текущий эпик Унги

## Расширенная система имитационного моделирования методом Монте-Карло

- market_portfolio_stress_monte_carlo_engine: Запуск нового эпика: создание базового движка Монте-Карло для симуляции распределения доходности портфеля.
- market_portfolio_stress_scenario_pipeline: Создается пайплайн стресс-сценариев, который напрямую связывает базовый движок Монте-Карло с автоматическим прогоном комплексных рыночных шоков.
- market_portfolio_stress_monte_carlo_engine: Создается агрегатор результатов Монте-Карло для обработки распределения доходностей и вычисления критических метрик хвостатого риска.
