# Текущий эпик Унги

## Антикоррупционная защита кода: Санитизация → Валидация → Автокоррекция → Применение

- code_sanitizer: Создание code_sanitizer закладывает фундамент для нового эпика, обеспечивая строгую фильтрацию синтаксических ошибок и запрещенных пустых исключений перед выполнением патчей.
- code_validator: Создание code_validator продолжает эпик, добавляя следующий уровень проверки после code_sanitizer для гарантии безопасности кода.
- patch_autocorrector: Создание patch_autocorrector продолжает эпик, добавляя этап автоматической коррекции кода между валидацией и применением патчей.
