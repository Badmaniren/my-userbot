# Текущий эпик Унги

## Аналитическая система качества и метрик репозитория

- repo_health_metric_validator: Создание базового агрегатора метрик как фундамента для нового эпика аналитики
- repo_health_metric_validator: Создает центральный узел для сбора данных, который свяжет разрозненные метрики в единую аналитическую базу.
- repo_health_metric_validator: Создание слоя агрегации, который превращает разрозненные данные от repo_health_metric_validator в структурированный аналитический поток.
