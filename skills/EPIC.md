# Текущий эпик Унги

## Система стресс-тестирования и восстановления портфеля

- market_portfolio_monitor: Создаем базовый модуль мониторинга восстановления портфеля после стресс-сценариев для инициализации нового многошагового эпика.
- market_portfolio_stress_scenario_pipeline: Комбинирует стресс-отчетность и мониторинг портфеля для завершения контура стресс-аналитики.
- market_portfolio_stress_recovery_coordinator_bridge: Комбинирует стресс-сценарии и мониторинг портфеля для продвижения контура восстановления после стресса, преодолевая прошлые провалы в интеграции.
- market_portfolio_stress_reporter: Укрепляем модуль стресс-отчетности для завершения контура стресс-тестирования и восстановления портфеля.
