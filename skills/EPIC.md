# Текущий эпик Унги

## Система визуализации дайджестов: Визуализатор → Экспортер → Дашборд

- anomaly_visualizer: Создание anomaly_visualizer начинает новый эпик визуализации данных, превращая сырые дайджесты в наглядные отчеты для операторов.
- digest_exporter: Модуль digest_exporter берет данные визуализации и стабильности для их последующего экспорта, продвигая эпик 'Система визуализации дайджестов'.
