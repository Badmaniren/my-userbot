# Текущий эпик Унги

## Система глубокого аудита и оповещения: аудит репозитория → генерация сводки → рассылка отчетов

- repo_auditor: Первый шаг эпика: создание базового модуля аудита репозитория для сбора первичных метрик качества и структуры.
- repo_reporter: Второй шаг эпика: связывание модуля аудита репозитория с генератором отчетов для автоматического формирования комплексной сводки.
- repo_notifier: Финальный шаг эпика: объединение аудита и нотификатора для автоматической доставки отчетов о состоянии репозитория.  ✅ ЭПИК ЗАВЕРШЁН
