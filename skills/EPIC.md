# Текущий эпик Унги

## Автоматизация жизненного цикла зависимостей: Внешний мониторинг → Анализ разрывов → Авто-обновление

- pypi_fetcher: Запуск нового эпика: создание инструмента для получения актуальных данных из внешнего индекса (PyPI), что является фундаментом для автоматического обнаружения устаревших библиотек.
- dependency_comparator: Реализация второго этапа эпика: создание логики сравнения (Gap Analysis) между локальным состоянием репозитория и внешними данными, полученными на предыдущем шаге.
- dependency_updater_pipeline: Финальный шаг эпика: связывание результатов сравнения версий (Gap Analysis) и автоматического обновления зависимостей в единый работающий пайплайн.  ✅ ЭПИК ЗАВЕРШЁН

Нет активного эпика — можно предложить новый.
