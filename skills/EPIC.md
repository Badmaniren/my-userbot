# Текущий эпик Унги

## Стресс-бэктестирование и симуляция устойчивости портфеля

- market_portfolio_stress_scenario_pipeline: Старт нового эпика: создание базового конвейера бэктестирования стресс-сценариев для оценки работы адаптивных стратегий.
- market_portfolio_stress_scenario_executor_bridge: Модуль интегрирует конвейер стресс-сценариев с симулятором для выполнения бэктестов устойчивости портфеля.
- market_portfolio_stress_ml_volatility_forecaster_v2: Интеграция предсказаний волатильности с конвейером стресс-сценариев для комплексного бэктестирования.
