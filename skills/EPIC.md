# Текущий эпик Унги

## Глобальная Децентрализованная Меш-Сеть: Узлы v1 -> Синхронизация -> Автономный Роутинг

- resilient_secure_global_mesh_node_v1: Создаем базовый узел меш-сети (v1) путем композиции глобального хаба v11 и автономного энтерпрайз-хаба v10 для запуска распределенной архитектуры.
- resilient_secure_global_mesh_node_v2: Создаем меш-узел v2 путем композиции узла v1 и экспортера аналитики для обеспечения синхронизации состояния между узлами децентрализованной сети.
- resilient_secure_global_mesh_router_v3: Создаем узел роутинга v3 на базе узла v2 и энтерпрайз-хаба v8, реализуя следующий шаг меш-сети — Автономный Роутинг.
