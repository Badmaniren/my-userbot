# Текущий эпик Унги

## Система оперативного реагирования на инциденты и сбои репозитория

- repo_health_dispatcher: Создаем первый модуль нового эпика для диспетчеризации и маршрутизации инцидентов здоровья репозитория
- repo_health_incident_tracker: Создаем модуль repo_health_incident_tracker для фиксации и отслеживания инцидентов, обнаруженных диспетчером.
- repo_health_incident_tracker: Дорабатываем repo_health_incident_tracker для стабильности работы системы оперативного реагирования на инциденты
- repo_notifier: Связываем модуль отслеживания инцидентов repo_health_incident_tracker с каналом оповещения repo_notifier для оперативной рассылки алертов о сбоях.
- repo_incident_remediator: Завершаем цикл оперативного реагирования: выполняем автоматическое устранение сбоев репозитория на основе зафиксированных инцидентов.  ✅ ЭПИК ЗАВЕРШЁН

Нет активного эпика — можно предложить новый.
