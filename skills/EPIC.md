# Текущий эпик Унги

## Система сбора и предиктивного анализа метрик здоровья репозитория

- repo_health_metric_validator: Создание первого модуля нового эпика для автоматизированного сбора метрик здоровья
- repo_health_collector: Создание надежного коллектора метрик с соблюдением правил обработки ошибок для продолжения текущего эпика
- repo_health_predictor_pipeline: Создание предиктивного анализатора на базе уже функционирующего коллектора метрик и валидатора для продолжения эпика здоровья репозитория.
- repo_health_remediator: Создание исполнителя исцеляющих мер (remediator) завершает цикл эпика здоровья репозитория, объединяя сбор метрик, их валидацию, предиктивный анализ и автоматическое устранение неполадок.  ✅ ЭПИК ЗАВЕРШЁН

Нет активного эпика — можно предложить новый.
