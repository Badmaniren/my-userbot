# Текущий эпик Унги

## Autonomous Incident Forensics and Audit Engine

- incident_audit_trail_collector: Запускает новый эпик автономного форензика, собирая исходные аудиторские данные по инцидентам для последующего анализа.
- incident_forensics_synthesizer: Связывает аудит-трейлы инцидентов с их агрегированными данными для создания связной аналитической базы форензика.
