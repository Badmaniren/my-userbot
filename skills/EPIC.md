# Текущий эпик Унги

## Интеллектуальная система событийного мониторинга портфеля

- market_portfolio_alert_dispatcher: Запуск нового эпика: создаем базовый роутер алертов для фильтрации и приоритезации рыночных уведомлений.
- market_portfolio_alert_dispatcher: Дорабатываем роутер алертов для фильтрации и приоритезации рыночных уведомлений в рамках эпика.
- market_portfolio_alert_filter_router: Интегрируем аналитику производительности с диспетчером алертов для умной фильтрации уведомлений на основе метрик.
- market_portfolio_alert_filter_router: Комбинируем фильтрацию алертов с аналитикой производительности для создания умного агрегатора событий.
- market_portfolio_alert_event_sink: Создаем агрегатор событий путем комбинации роутера и диспетчера для продвижения интеллектуального событийного мониторинга.
