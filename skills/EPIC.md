# Текущий эпик Унги

## Аудит и безопасность инвестиционных данных

- market_portfolio_audit_log_exporter: Создаем базовый модуль аудита логов для обеспечения прозрачности операций и фиксации всех изменений в системе.
- market_portfolio_audit_compliance_hub: Модуль комплаенса связывает экспорт логов с хранилищем данных для глубокой проверки целостности инвестиционного аудита.
