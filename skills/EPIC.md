# Текущий эпик Унги

## Анализ и агрегация потока инцидентов репозитория

- repo_health_incident_tracker: Создание первого шага нового эпика по централизованному сбору и агрегации инцидентов для последующей умной маршрутизации.
- repo_health_incident_tracker: Оптимизация и доработка логики repo_health_incident_tracker для надежной обработки инцидентов перед передачей в диспетчер.
- repo_health_dispatcher: Доработка диспетчера инцидентов для завершения текущего цикла агрегации и маршрутизации инцидентов репозитория.
