# Текущий эпик Унги

## Система оповещений и нотификаций: Диспетчер → Шаблонизатор → Интеграция с вебхуками → Автоматический дайджест

- notification_channel_dispatcher: Создаем базовый диспетчер каналов оповещений для отправки критических сбоев и отчетов о самовосстановлении
- notification_template_engine: Создаем шаблонизатор уведомлений, который будет использовать диспетчер каналов (notification_channel_dispatcher) для форматирования сообщений об инцидентах перед отправкой
