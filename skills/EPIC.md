# Текущий эпик Унги

## Автоматизированная система регрессионного тестирования патчей

- patch_regression_hub: Создание ядра регрессионного тестирования патчей для обеспечения стабильности и безопасности автофиксации кода.
- patch_regression_hub: Исправление багов в patch_regression_hub для завершения этапа регрессионного тестирования патчей.
- patch_regression_listener: Создание слушателя патчей связывает ядро регрессионного тестирования с потоком поступающих исправлений.
- patch_evaluator: Реализация PatchEvaluator обеспечивает предварительный анализ диффов на регрессионные риски перед запуском регрессионного цикла тестирования
- patch_regression_hub: Исправление ошибок в patch_regression_hub для завершения этапа регрессионного тестирования патчей.
- patch_regression_listener: Рефакторинг patch_regression_listener закрывает уязвимые места и позволяет успешно завершить интеграцию слушателя с ядром регрессии.
