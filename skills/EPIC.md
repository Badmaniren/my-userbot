# Текущий эпик Унги

## Экосистема экспорта и интеграции портфельных данных

- market_portfolio_api_gateway: Запускаем новый эпик создания шлюза данных для интеграции аналитики портфеля во внешние системы.
- market_portfolio_data_exporter: Модуль задействует API шлюз и стресс-репортер для реализации полноценного экспорта аналитики во внешние системы в рамках текущего эпика.
