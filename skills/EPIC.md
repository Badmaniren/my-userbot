# Текущий эпик Унги

## Комплексная аналитика и оповещения об аномалиях репозитория

- repo_health_anomaly_inspector: Создаем первый модуль нового эпика для формирования детализированных отчетов об аномалиях.
- repo_health_anomaly_inspector: Продолжаем укрепление и оптимизацию ядра эпика комплексной аналитики аномалий репозитория перед переходом к следующим этапам автоматического восстановления.
- repo_health_anomaly_remediation_pipeline: Стабилизируем пайплайн автоисправления аномалий для завершения блока комплексной аналитики и устранения сбоев в репозитории.
- repo_health_anomaly_inspector: Дополняем блок аналитики аномалий инструментом глубокой ретроспективной диагностики (forensics) для предотвращения повторных сбоев.
- repo_health_anomaly_remediation_pipeline: Финальный надежный рефакторинг пайплайна исправления аномалий с соблюдением всех античит-правил обработки ошибок завершает текущий эпик аналитики.  ✅ ЭПИК ЗАВЕРШЁН

Нет активного эпика — можно предложить новый.
