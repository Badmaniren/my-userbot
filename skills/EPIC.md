# Текущий эпик Унги

## Продвинутый предиктивный риск-менеджмент портфеля

- market_portfolio_stress_monte_carlo_engine: Запуск нового эпика для интеграции сценарного анализа и прогнозирования рисков портфеля.
- market_portfolio_predictive_var_engine: Интеграция прогнозной модели волатильности с симулятором Монте-Карло для предиктивного расчета стрессовых квантилей риска (VaR/CVaR).
