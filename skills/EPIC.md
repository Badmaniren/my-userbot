# Текущий эпик Унги

## Самодиагностика и телеметрия: Сбор метрик → Детекция аномалий → Автокоррекция → Дайджест стабильности

- anomaly_detector: Создание модуля anomaly_detector закладывает основу для мониторинга стабильности автономного движка и отлова сбоев на ранних стадиях.
- system_telemetry: Создание system_telemetry закрывает следующий шаг текущего эпика 'Сбор метрик → Детекция аномалий', обеспечивая сырыми данными anomaly_detector.
