# Текущий эпик Унги

## Система самонаблюдения и телеметрии: сбор метрик → анализ производительности → автооптимизация конвейера

- system_telemetry: Создаем базовый модуль телеметрии для мониторинга работы системы и сбора метрик выполнения.
- telemetry_optimizer: Связывает собранные в system_telemetry метрики с error_pipeline для реализации этапа автоматической оптимизации конвейера производительности.
