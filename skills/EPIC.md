# Текущий эпик Унги

## ML-прогнозирование и предиктивная аналитика стресс-тестов портфеля

- market_portfolio_stress_ml_volatility_forecaster_v2: Создание надежного модуля предиктивной аналитики волатильности для предсказания рисков портфеля при стресс-сценариях без использования запрещенных заглушек.
- market_portfolio_stress_ml_volatility_forecaster_v2: Создаем полноценный модуль предиктивной аналитики для выявления и прогнозирования аномалий в стресс-тестах портфеля, развивая ML-направление текущего эпика.
- market_portfolio_ml_feature_builder: Создает фундамент для предиктивных ML-моделей стресс-анализа: извлекает статистические фичи и хвостовые характеристики доходностей, необходимые для обучения и скоринга риска.
- market_portfolio_ml_stress_evaluator: Связывает генератор хвостовых фичей и прогноз волатильности в единый скоринг стресс-риска портфеля, продвигая предиктивный контур эпика.
- market_portfolio_ml_stress_adaptive_allocator: Завершает эпик интеграцией ML-скоринга рисков с реальным контуром автоматического реагирования и ребалансировки портфеля.  ✅ ЭПИК ЗАВЕРШЁН
