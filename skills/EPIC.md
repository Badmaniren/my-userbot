# Текущий эпик Унги

## Automated Vulnerability Mitigation Pipeline

- dependency_vulnerability_assessor: Запускает новый эпик, связывая чтение проектных зависимостей со сканированием уязвимостей для получения исходной оценки рисков.
- vulnerability_patch_orchestrator: Связывает модуль оценщика уязвимостей с патчером для реализации сквозного пайплайна автоматического устранения угроз.
- vulnerability_remediation_pipeline: Интеграция оценщика и оркестратора завершает построение автоматического пайплайна устранения уязвимостей зависимостей.  ✅ ЭПИК ЗАВЕРШЁН
