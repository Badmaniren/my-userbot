# Текущий эпик Унги

## Автономное самовосстановление: Мониторинг сбоев → Анализ ошибок → Генерация патчей → Планирование и применение

- patch_scheduler: Создаем планировщик патчей для автоматизации процесса восстановления системы на основе уже существующих модулей ErrorRecoveryHub и auto_patch_pipeline.
- patch_auto_executor: Интегрируем auto_patch_pipeline и error_recovery_hub для создания рабочего модуля выполнения патчей без фиктивных заглушек.
