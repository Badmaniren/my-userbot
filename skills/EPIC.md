# Текущий эпик Унги

## Система комплексного мониторинга и восстановления здоровья репозитория

- repo_health_diagnostic: Создание базового модуля диагностики для дальнейшей интеграции с системами мониторинга и автоматического восстановления
- repo_health_restorer: Используем готовый диагностический модуль для создания шага восстановления здоровья репозитория.
