# Текущий эпик Унги

## Комплексный стресс-анализ и сценарное моделирование портфеля

- market_portfolio_stress_scenario_pipeline: Создание фундамента для сценарной матрицы стресс-тестирования, расширяющего возможности оценки устойчивости портфеля.
- market_portfolio_stress_scenario_pipeline: Доработка конвейера стресс-сценариев для успешного прохождения тестов и стабилизации комплексного эпика стресс-анализа портфеля.
- market_portfolio_stress_monte_carlo_engine: Улучшение стабильности и точности модуля Монте-Карло для укрепления общего конвейера комплексного стресс-анализа портфеля
- market_portfolio_stress_reporter: Рефакторинг отчета по стресс-тестированию завершает цикл стабилизации ключевых компонентов текущего эпика стресс-анализа портфеля.
