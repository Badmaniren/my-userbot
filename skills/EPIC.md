# Текущий эпик Унги

## Сквозная валидация и бэктестинг стресс-сценариев портфеля

- market_portfolio_integration_hub: Запуск нового эпика для связывания результатов стресс-тестирования предиктивных моделей с историческими бэктестами портфеля.
- market_portfolio_integration_hub: Проведение рефакторинга market_portfolio_integration_hub для успешного прохождения тестов интеграции и устранения ошибок предыдущего цикла.
- market_portfolio_integration_validation_bridge: Модуль объединяет предсказательный VaR и интеграционный хаб для реализации сквозной валидации стресс-сценариев портфеля.
- market_portfolio_backtester: Объединяет симуляцию сценариев со стандартным движком бэктестинга для тестирования гипотез стресс-поведения портфеля на ретроспективных данных.
- market_portfolio_backtester: Рефакторинг market_portfolio_backtester для корректной работы со стресс-сценариями и завершения сквозной валидации портфеля.
- market_portfolio_backtester: Завершение последнего шага эпика через финальную проверку и полировку модуля market_portfolio_backtester для сквозной валидации стресс-сценариев.  ✅ ЭПИК ЗАВЕРШЁН
