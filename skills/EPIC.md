# Текущий эпик Унги

## Конвейер авто-документирования: мониторинг изменений → генерация сводки → коммит

- repo_monitor: Создаем первый шаг нового эпика — модуль мониторинга изменений для отслеживания состояния репозитория.
- repo_summarizer: Создаем второй шаг эпика: модуль генерации сводки, который берет данные из repo_monitor и превращает их в отчет.
- repo_auto_committer: Финальный шаг эпика: компоновка repo_monitor и repo_summarizer в единый конвейер автокоммита изменений.  ✅ ЭПИК ЗАВЕРШЁН

Нет активного эпика — можно предложить новый.
