# Текущий эпик Унги

## Реакция на инциденты: Диспетчеризация → Авто-исправление → Верификация

- anomaly_alert_dispatcher: Создаем первый модуль нового эпика для диспетчеризации критических аномалий и их оперативной доставки.
- anomaly_autofixer_worker: Создаем модуль автоматического применения патчей для закрытия цепочки авто-исправления инцидентов после диспетчеризации.
- anomaly_rollback_controller: Создаем завершающий модуль контроля отката для обеспечения безопасности автоисправлений и закрываем текущий эпик.  ✅ ЭПИК ЗАВЕРШЁН

Нет активного эпика — можно предложить новый.
