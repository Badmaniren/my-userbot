# Текущий эпик Унги

## Аудит безопасности зависимостей: PyPI клиент → парсер зависимостей → аудит уязвимостей → генератор отчетов

- pypi_client: Создаем базовый клиент PyPI для получения метаданных и зависимостей пакетов — фундамент для анализа безопасности экосистемы.
- package_requirement_reader: Создаем парсер зависимостей для обработки метаданных, полученных через pypi_client, что является следующим шагом аудита безопасности.
